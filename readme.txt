Lightweight, easy to use and flexible classic WordPress theme for beginners and advanced website creators. Provides a clean, flexible foundation with no unnecessary code, while making it easy to add CSS and JS frameworks or libraries as needed.

== Description ==

BootCMS is a lightweight and flexible classic WordPress theme designed as a clean foundation for website development.

It provides a range of layouts and simple styling options through the WordPress Customizer, while allowing developers to work directly with HTML, CSS and JS through its flexible sidebar and widget areas and the included Large HTML Editor. CSS and JavaScript frameworks or libraries can also be added as needed.

BootCMS includes support for Bootstrap, Foundation and Bulma, as well as its native BootCMS CSS framework. It also provides one-click activation of the React and/or Vue JavaScript frameworks, along with one-click selection from a range of CSS themes provided by BootCMS and Bootswatch. 

A detailed Help system is included.

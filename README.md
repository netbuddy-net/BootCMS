# BootCMS
BootCMS is a **lightweight**, **easy to use** and **flexible classic** WP theme for beginners and advanced website creators. Provides a clean, flexible foundation with no unnecessary code, while making it easy to use CSS and JS frameworks or libraries as needed. Includes a comprehensive *Help* system.

Using the native BootCMS CSS library helps novice developers apply styles with just a few clicks in the **WordPress Customizer**. This does not prevent advanced developers from adding widgets wherever needed and editing their own code.

The Vanilla CSS theme is part of the BootCMS presentation framework, included with the BootCMS WordPress Classic Theme. It provides basic website styling as well as ready-to-use components, such as forms and pagination.

It is based on the Bootstrap 5.x style library but does not include its JavaScript

 (function () { 'use strict';
 document.querySelectorAll('.needs-validation').forEach(form => {
  const fields = form.querySelectorAll('input, select, textarea'),
   messages = ['valid-submit-feedback','invalid-submit-feedback',
    'valid-submit-tooltip','invalid-submit-tooltip'].map(c => form.querySelector('.' + c)),
   hide = () => messages.forEach(m => { if (m) m.style.display = 'none'; }),
   check = f => {
    f.classList.toggle('is-valid', f.checkValidity());
    f.classList.toggle('is-invalid', !f.checkValidity()); };
  fields.forEach(f => {
   f.addEventListener('input', () => { check(f); hide(); });
   f.addEventListener('change', () => { check(f); hide(); });
   f.addEventListener('blur', () => check(f)); });
  form.addEventListener('submit', e => {
   const valid = form.checkValidity();
   if (!valid) { e.preventDefault(); e.stopPropagation(); }
   form.classList.add('was-validated');
   messages.forEach((m, i) => {
    if (m) m.style.display = (i % 2 === (valid ? 0 : 1)) ? 'block' : 'none'; }); });
  form.addEventListener('reset', () => {
   form.classList.remove('was-validated');
   fields.forEach(f => f.classList.remove('is-valid', 'is-invalid'));
   hide(); });
 }); })();

 var slider = wrapper.querySelector(".scale");
 var output = wrapper.querySelector(".range-tooltip");
 function updateScale() {
  output.textContent = slider.value;
  var min = Number(slider.min || 0);
  var max = Number(slider.max || 100);
  var percent = max === min ? 0 :
  (Number(slider.value) - min) / (max - min);

  updateScale();

  output.style.display = "none"; });

The "floated messages" are hidden and can be shown using a standard button, a button styled to look like a link (as shown above), or a JavaScript trigger (also shown above) that can be included in any JavaScript script.

There are two types of "floated messages", one that is always displayed in the bottom-right corner of the browser window, and another that is displayed near the triggering button, at the top center by default.

The button that opens the "floated message" must reference the message's id (popovertarget="theID") and have the classes: btn and btn-variant, where variant is one of the following: 'primary', 'secondary', 'info', 'success', 'warning', 'danger', 'light', 'dark' or 'link'.

The button that opens a "floated message" positioned next to the button must also reference the message's id and have the same classes, plus the following style attribute: style="--anchor-name: message-one;". Replace 'message-one' with a unique name, such as message-two, for each additional button.

"Floated messages" must be placed inside a paragraph element, <p class="alert alert-variant">. The paragraph must be wrapped in a <div> with an 'id' that the button will reference. The div must also have the following attributes exactly as shown:
<div id="anyID" class="alert-positioned" role="alert" popover>.

The "close" button (x) at the end of the "floated message" must have the following attributes:
<button class="btn-close" popovertarget="theID" popovertargetaction="hide" aria-label="Close"></button>.

The "floated messages" can be closed by clicking anywhere outside them in the browser window. If this behaviour is not desired, they can be closed only by clicking their own close button or the button that opened them. To achieve this, add the attribute 'popover="manual"' to the popover <div>.

14 emojis to use as badges

Badges are supported on the following elements: heading, button, span, div, a, figure, picture, table, ul, and ol. There are two types of badges text and emoji. To create text badges use the classes 'badge-text', and 'badge-variant' where 'variant' is one of the following: 'primary', 'secondary', 'info', 'success', 'warning', 'danger', 'light' or 'dark'.

To specify the badge text, use the following inline style: style="--badge-text: 'The Text Here';".

To use a text badge (class: badge-text) as a counter, JavaScript or another method is required to update its value dynamically. Use the inline style style="--badge-text: '&nbsp;&nbsp;';", where the two non-breaking spaces are a placeholder for the number that will be updated. For an unspecified counter, use the two non-breaking spaces to display an empty badge.

To use one of the 14 emojis as a badge, use the class badge-emoji, where 'emoji' is one of the following: new, cool, free, okay, notice, money, yes, not, star, info, success, warning, danger, or registered.

There are two ways to implement pagination for split pages: manually, which is a good option when there are only a few pages, or automatically, using a server-side language such as PHP or JavaScript. Pagination consists of an unordered list <ul> inside a <nav> element. Each list item contains a link <a>.

Two pagination styles are available:

  • Block Pagination: The pagination is centred at the bottom of each page. Developers can specify the number of page numbers displayed using the '--pages-visible' CSS variable in the 'pagination' class. The default is 3.
  • Previous-Next Pagination: Only the "Previous" and "Next" buttons are displayed at opposite ends of the page bottom, with the current page number shown between them.

The following JavaScript is required to generate the dynamic pagination.

 document.querySelectorAll('.pagination').forEach(p => {
  const previousNext = p.classList.contains('previous-next');
  const prev = document.createElement('li');
  prev.className = 'page-item';
  prev.innerHTML = `<a class="page-link" href="#" aria-label="Previous">
   ${previousNext ? 'Previous' : '<span aria-hidden="true">&laquo;</span>'} </a>`;
  const next = prev.cloneNode(true);
  next.querySelector('a').innerHTML = previousNext ? 'Next' : '<span aria-hidden="true">&raquo;</span>';
  next.querySelector('a').setAttribute('aria-label', 'Next');
  if (!previousNext) {
   prev.querySelector('a').dataset.pageStep = '-1';
  next.querySelector('a').dataset.pageStep = '1'; }
  p.prepend(prev);
  p.append(next);
  const dotsBefore = document.createElement('li');
  dotsBefore.className = 'page-item';
  dotsBefore.innerHTML = '<span class="page-link">…</span>';
  const dotsAfter = dotsBefore.cloneNode(true);
  const pages = [...p.querySelectorAll('.page-item')] .filter(li => /^\d+$/.test(li.textContent.trim()));
  const count = +getComputedStyle(p) .getPropertyValue('--pages-visible').trim() || 3;
  let start = Math.max(0, Math.min(
   pages.findIndex(li => li.classList.contains('active')) - Math.floor(count / 2),
   pages.length - count ));
  function show() {
   if (previousNext) {
    const items = [...p.querySelectorAll('.page-item')] .filter(li => li !== prev && li !== next);
    const current = items.findIndex(li => li.classList.contains('active'));
    if (current < 0) return;
    const findPage = (step) => {
     for (let i = current + step; i >= 0 && i < items.length; i += step) {
      const a = items[i].querySelector('a');
      if (a && !items[i].classList.contains('disabled')) return a; }
    return null; };
    const before = findPage(-1);
    const after = findPage(1);
    const prevLink = prev.querySelector('a');
    const nextLink = next.querySelector('a');
    prev.classList.toggle('disabled', !before);
    next.classList.toggle('disabled', !after);
    prevLink.setAttribute('aria-disabled', String(!before));
    nextLink.setAttribute('aria-disabled', String(!after));	
    if (before) prevLink.href = before.href;
    if (after) nextLink.href = after.href;
    items.forEach(li => {
     li.style.display = li === items[current] ? '' : 'none'; });
    prev.style.display = '';
    next.style.display = '';
   } else {
    pages.forEach((li, i) =>
     li.style.display = i >= start && i < start + count ? '' : 'none' );
    dotsBefore.remove();
    dotsAfter.remove();
    if (start > 0) pages[start].before(dotsBefore);
    if (start + count < pages.length)
    pages[start + count - 1].after(dotsAfter);
    prev.classList.toggle('disabled', start === 0);
    next.classList.toggle('disabled', start + count >= pages.length);
    prev.querySelector('a').setAttribute('aria-disabled', start === 0);
    next.querySelector('a').setAttribute('aria-disabled', start + count >= pages.length); }
  p.style.display = 'flex'; }
  if (!previousNext) {
   p.querySelectorAll('[data-page-step]').forEach(a =>
    a.addEventListener('click', e => {
     e.preventDefault();
     if (a.getAttribute('aria-disabled') === 'true') return;
     start = Math.max(0, Math.min(
     start + (+a.dataset.pageStep) * count,
     pages.length - count ));
     show(); })
  ); }
  show();
});

 function updateStepper(currentStep) {
  const steps = document.querySelectorAll('#dynamic-stepper .step');
  steps.forEach((step, index) => {
   step.classList.remove('completed', 'in-progress', 'pending');
   if (index + 1 < currentStep) {
    step.classList.add('completed');
    step.dataset.status = 'Completed';
   } else if (index + 1 === currentStep) {
    step.classList.add('in-progress');
    step.dataset.status = 'In progress';
   } else {
    step.classList.add('pending');
    step.dataset.status = 'Pending'; }
 }); }

 document.querySelectorAll('.carousel').forEach(carousel => {
  const slides = [...carousel.querySelectorAll('.carousel-item')];
  const dots = [...carousel.querySelectorAll('.carousel-indicators button')];
  const interval = Number(carousel.dataset.bsInterval) || 4000;
  const autoplay = carousel.dataset.bsRide === 'carousel' && slides.length > 1;
  let index = Math.max(0, slides.findIndex(s => s.classList.contains('active')));
  let timer;
  const show = i => {
    index = (i + slides.length) % slides.length;
    slides.forEach((s, n) => s.classList.toggle('active', n === index));
    dots.forEach((d, n) => {
      d.classList.toggle('active', n === index);
      n === index ? d.setAttribute('aria-current', 'true') : d.removeAttribute('aria-current');
    }); };
  const start = () => {
    clearInterval(timer);
    if (autoplay) timer = setInterval(() => show(index + 1), interval); };
  carousel.addEventListener('click', e => {
    const c = e.target.closest('.carousel-control-prev, .carousel-control-next, [data-bs-slide-to]');
    if (!c || slides.length > 2) return;
    show(c.hasAttribute('data-bs-slide-to')
      ? Number(c.dataset.bsSlideTo)
      : index + (c.classList.contains('carousel-control-next') ? 1 : -1));
    start(); });
  carousel.addEventListener('pointerdown', e => {
    if (!e.target.closest('button')) clearInterval(timer); });
  ['pointerup', 'pointerleave', 'pointercancel'].forEach(ev => carousel.addEventListener(ev, start));
  let startX = 0, startY = 0;
  carousel.addEventListener('pointerdown', e => { startX = e.clientX; startY = e.clientY; });
  carousel.addEventListener('pointerup', e => {
    if (e.target.closest('button')) return;
    const dx = e.clientX - startX, dy = e.clientY - startY;
    if (Math.abs(dx) > 50 && Math.abs(dx) > Math.abs(dy) * 1.5) show(index + (dx < 0 ? 1 : -1));
  });
  start(); 
 });

Layout Utilities

Since this stylesheet is based on Bootstrap 5, Bootstrap's layout utilities can also be used. However, BootCMS provides a few ready-made classes for more complex layouts.

Class: bootcms-flex-stretch
Arranges items horizontally within their container, with additional layout options using the variables and classes below. Items stretch vertically to match the height of the tallest.
Must also include one of the classes below.
Inline variables: --bootcms-flex-gap, --bootcms-flex-size. Set to a value in rem, em, px, etc.
Class equal: Equal distribution, with a minimum width if desired.
Class auto: Uses a preferred starting width, then grows to fill available space or wraps onto additional rows.
Class: bootcms-flex-column
Arranges items vertically within their container, with additional layout options using the variables and classes below.
Inline variables: --bootcms-flex-gap, --bootcms-flex-size. Set to a value in rem, em, px, etc.
Class start: Align to the start horizontally.
Class center: Centre horizontally.
Class end: Align to the end horizontally.
Class equal: All containers use the width specified by the variable.
Class auto: All containers use the width specified by the variable, with a minimum of half that width and a maximum of 100%.
No added class: Stretching to fill the available width of the container.
Class: bootcms-flex-center
Centres items horizontally and vertically within their container, with additional layout options using the variables below.
Inline variables: --bootcms-flex-gap, --bootcms-flex-max, --bootcms-flex-min. Set to a value in rem, em, px, etc.
Class: grid-3x2-34
A grid of four containers arranged in two rows and three columns within a parent container. The third column spans both rows, while the first item in the second row spans two columns. By default, all columns share the available width equally.
Inline variables: --bootcms-grid-gap. Set to a value in rem, em, px, etc.
Class: grid-2x3-12
A grid of four containers arranged in two rows and three columns within a parent container. The first column spans both rows, while the second item in the first row spans two columns. By default, all columns share the available width equally.
Inline variables: --bootcms-grid-gap. Set to a value in rem, em, px, etc.
Class: grid-3x3-34
A grid of six containers arranged in three rows and three columns within a parent container. The third column spans all rows, while the fourth item spans column one and two in the second row. By default, all columns share the available width equally.
Inline variables: --bootcms-grid-gap. Set to a value in rem, em, px, etc.

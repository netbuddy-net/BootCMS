Top Container - BootCMS Classes

Select one of the two options based on how the page should be displayed. For an edge-to-edge wide page (100% width), select Fluid Container (always 100% wide). For a page width that responds to the browser's width and becomes one of the five widths, 576px, 768px, 992px, 1200px and 1400px, select Container with Breakpoints.

BootCMS Header Text Color

Click on the colour picker and choose the desired colour for the text in the Header.

BootCMS Header Background Color

Click on the colour picker and choose the desired colour for the background of the Header.

Use Header Image as background

Select the checkbox to use the uploaded image as the Header background (sized as "cover") instead of displaying it as a standard image.

BootCMS Navbar Text Color

Click on the colour picker and choose the desired colour for the text in the primary Navigation bar.

BootCMS Navbar Background Color

Click on the colour picker and choose the desired colour for the background of the primary Navigation bar.

BootCMS Navbar Position Styles

Choose one of the four options for the position of the primary Navigation bar:
1. Placed after Header
This is the default and most popular position.
2. Place on Top
An alternative position above the Header, at the top of the page.
3. Fixed on Top
With this option, the Navbar is fixed permanently at the top of the page and does not scroll away.
4. Sticky on Top
With this option the Navbar is placed in its default position, but when it is scrolled away, it stays at the the top of the page in the viewport.

BootCMS Main Content Text Color

Click on the colour picker and choose the desired colour for the text in the Main section of the page.

BootCMS Main Content Background Color

Click on the colour picker and choose the desired colour for the background of the Main section of the page.

BootCMS Main Content Background Image

Use the image control to select an image for the background of the Main section. The image will "cover" the whole background. It is possible to adjust the background image by creating class styles for the Main tag under the "Additional CSS" section.

Background Image as Watermark

The background image can be used as a watermark on a page. In this way, the image will be positioned in the centre of the page and will keep its original size. However, its size can be adjusted with styles.

BootCMS Right Sidebar Text Color

If a Right Sidebar has been enabled, use the colour picker to choose the desired colour for the text in the Right Sidebar.

BootCMS Right Sidebar Background Color

If a Right Sidebar has been enabled, use the colour picker to choose the desired colour for the background in the Right Sidebar.

BootCMS Right Sidebar Width

It is possible to adjust the ratio between the Main section and the Right Sidebar if the Right Sidebar has bee enabled. Use the dropdown control to select one of several options. The default is 25% for the Right Sidebar.

BootCMS Footer Text Color

Click on the colour picker and choose the desired colour for the text in the Footer of the page.

BootCMS Footer Background Color

Click on the colour picker and choose the desired colour for the background of the Footer of the page.

BootCMS Page Background Color

Developers can apply a background colour on the whole webpage instead of applying it to each section separately. Click on the colour picker and choose the desired colour for the whole page background.

BootCMS Page Background Image

Use the image control to select an image for the background of the whole page. The image will "cover" the whole background.

Enable Image as Tiles

Select the checkbox to use the background image as tiles filling the page background.

Background tiles starting position

Choose one of the two options to configure the tiles to start from the "top left" or "centre" of the background.

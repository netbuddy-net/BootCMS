Menus

BootCMS registers a menu location named "Primary Navigation", placed under the Header of the page. This location can be used for the site's main navigation menu.

Create New Menu

Click on Create New Menu button to create a menu for this position.

Menu Name
In the new interface, enter a name for the menu in the "Menu Name" input box.
Menu Location
Check the "Primary Navigation" checkbox and click the Next button.

On the next interface, leave the "Menu Name" unchanged and make sure the "Primary Navigation" checkbox remains checked.
Menu Options
Optionally, check the "Automatically add new top-level pages to this menu" checkbox to allow WordPress to automatically add newly created pages to the menu.

Add Items

Click the Add Items button. A sliding sidebar will appear displaying the available webpages. Click each webpage to be added to the menu. When finished, click the Publish button at the top.

Submenus
It is possible to create submenus by dragging a webpage slightly to the right. This will create a larger indent to the left, indicating that the webpage is now a submenu item. The menu item above the "submenu" will act as the control for showing and hiding the submenu. It is advisable to use a Custom Link for this purpose. Enter a hash (#) in the URL field and a meaningful title in the Link Text input box.

Menus

WordPress creates a link in the "Menus" section for each menu, using its name. Click on a link to open the interface for configuring the corresponding menu.

Customised Nav Menu Sidebar

WordPress menus can also be added to the Sidebars using the Navigation Menu widget. If a hardcoded menu is required in "Primary Navigation" instead of a menu constructed by WordPress, add a Custom HTML widget or a Large HTML Editor widget to the "Customised Nav Menu Sidebar".

BootCMS Menu Classes

BootCMS provides two classes for easily creating a Disabled Link and a Divider Line. Read in this section how to use them.

Menu Locations

Click the View All Locations link. The new interface will display the registered location "Primary Navigation". This provides another way to select the Menu assigned to this location.

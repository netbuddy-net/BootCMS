Site Identity

Here is where a developer should start, by creating the website's identity and related information.

Site Title and Tagline

It is essential to enter a Site Title and Tagline, since BootCMS uses both as the page's "Heading Level 1" in the website header.

Site Icon (favicon)

It is also highly advisable to select a Site Icon also known as a "Favicon". It is displayed in the browser's tab and can also be displayed by BootCMS in some of the "Menu Bar" setups.

Site Logo

If a logo image is to be used, select one here using the Site Logo control.

Copyright Name and Copyright Notice

The following options are added by BootCMS. In Copyright Name enter the name of the entity (person or company) responsible for the website. In Copyright Notice enter any notice regarding copyright restrictions or rights granted. BootCMS will add this information to the last line at the bottom of all pages.

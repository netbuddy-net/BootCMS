Header & Body Background Image

Header Image

Click the "Add Image" control to upload an image file to be placed in the page header. The theme works best with an image aspect ratio of 4:3. It is possible to crop the image after uploading it to achieve a perfect fit.

This is a function provided by WordPress, however the image can be side-by-side with BootCMS's Header Right Sidebar content.

Body Background Image

This is a function provided by WordPress. The image is applied to the body tag, whereas BootCMS's background images are applied to the 'main' and 'html' tags. This gives developers complete flexibility to combine and apply background images as they wish, with the help of just a few controls.

Image Position

Use this control to position the background image according to the interactive diagram displayed in the control.

Image Size

Choose one of the three available options: Original size, Fit to Screen, or Fill Screen.

Repeat Background Image & Scroll with Page

If the image needs to be used as a tile, check the "Repeat Background Image" checkbox.

By default, the background image remains fixed in the background. If you want it to scroll along with the page content, check the "Scroll with Page" checkbox. The effects of these two checkboxes are independent of each other.

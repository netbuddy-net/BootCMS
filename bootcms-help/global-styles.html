Adding Classes to Top-Level Containers

  • Body Classes. Enter the names of custom or framework classes to apply to the body tag.
  • Top Container Classes. The div immediately inside the body tag, which wraps the header, nav, main and footer, is used to apply responsive classes to the web page. Enter the names of custom or framework classes to apply to this div (id="top-container").
  • Header Classes. Enter the names of custom or framework classes to apply to the header tag.
  • Nav Tag Classes. Enter the names of custom or framework classes to apply to the main nav tag. Some frameworks require specific classes to be applied here for the navigation menu to work correctly.
  • Main Tag Classes. Enter the names of custom or framework classes to apply to the main tag.
  • Footer Classes. Enter the names of custom or framework classes to apply to the footer tag.

Header Section

By default, the Header content includes the Site Title in an "h1" tag, with the Tagline displayed underneath inside a "small" tag, part of the "h1". There is also a Header Right Sidebar where widgets can be used to add content and HTML code. To replace the default Header layout, add a widget to the Custom Header.

To display the Site Title and Tagline as explained above, the "Display Site Title and Tagline" checkbox in the Site Identity section must be checked.

Alternatively, use the WordPress Header Image section in the Customizer to add a "Header Image". This replaces the default header content while retaining the option to use the Header Right Sidebar to add content and HTML code to the header.

Theme Header Image

For all frameworks, BootCMS provides an option to add an image to the page's "Header" by using the Theme Header Image control.
The image layout is adjusted automatically:

  • Near-square images ➡️ Placed to the left of "Title" and "Tagline".
  • Wide-format images ➡️ Placed above the "Title" and "Tagline".

Display the Logo

If instead of the Theme Header image, need to display the "logo" on the left of the Header, select the Display the Logo in the header instead of the Theme Header image checkbox. It is also possible to display the logo in the left sidebar of the "Footer" by selecting the Display the Logo in the footer checkbox.

Footer Section

By default, the Footer includes three sections: A "Left" sidebar, a "Main" and the "Right" sidebar. Use widgets to add content and HTML code. It also includes a bottom section that displays copyright information. To replace the Footer's default layout, add a widget to the Custom Footer.

Top Container - Framework Classes

In the Top Container - Framework Classes input box, enter style class names for the Top Container (div) tag. "Top Container" is a div tag which contains all of the sections of a webpage that are displayed in the browser, such as the header, main and footer. Multiple classes can be separated by spaces. You can use classes from an installed CSS Framework, or define custom classes under the "Additional CSS" section.

Header Image - Global

For all frameworks, there is an option to add an image to the page's "Header" by using the Header Image - Global control.
The image layout is adjusted automatically:

  • Near-square images ➡️ Placed to the left of "Title" and "Tagline".
  • Wide-format images ➡️ Placed above the "Title" and "Tagline".

Display the Logo - Global

If instead of an image, need to display the "logo" on the left of the Header, select the Display the Logo in the header instead of the Header Image checkbox. It is also possible to display the logo on the left of the "Footer" by selecting the Display the Logo in the footer checkbox. Nav Tag Classes - Global

Nav Tag Classes - Global

Use the input box to add, remove or replace CSS classes for the Nav tag. Multiple classes can be separated by spaces. You can use classes from an installed CSS Framework, or define custom classes under the "Additional CSS" section.

"Main" Tag Classes - Global

Also here, use the input box to add, remove or replace CSS classes for the Nav tag. Multiple classes can be separated by spaces. You can use classes from an installed CSS Framework, or define custom classes under the "Additional CSS" section.

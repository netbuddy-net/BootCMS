Posts Settings

Posts Homepage Title

To replace the default title of the Posts Homepage, whether it displays the "latest posts" or a "static page", enter the desired title in the input box.

Post Metadata

Use the checkboxes here to enable or disable the display of the post metadata under the post title. The metadata can be styled using the "Additional CSS" section, the relevant classes are displayed below.

  1. Published date - The date when the post was first published (class: "posted-on")
  2. Modified date - The date when the post was last modified (class: "modified-on")
  3. Author - The author of the post (class: "posted-by")
  4. Category - The category or categories to which the post belongs (class: "posted-in")
  5. Tags - The tag or tags associated with the post (class: "posted-tags")
  6. Comment count - The number of the comments the post has (class: "comments-count")
  7. Discussion status - "Open" or "Close", allowing readers to know whether they can comment on the post (class: "discussion-status")

Post Content

Use the radio button options to choose whether the lists of posts display the full post content or an excerpt.

Auto Excerpt Length

Use the input box to set the maximum number of words used for WP automated excerpts. The maximum number accepted is 999, the default is 55.

Call to Action code in Single Post

Use the "textarea" box to enter HTML/CSS/JS for the Call to Action area shown at the end of the content of a single post. A maximum of 1500 characters is supported.

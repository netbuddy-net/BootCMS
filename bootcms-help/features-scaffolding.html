Features & Scaffolding

Introduction

There is often an antagonism between simplicity and advanced configuration. Themes can become restrictive when trying to support too many options, but this is an area where BootCMS aims to provide a different approach. BootCMS provides easy-to-use tools for developers of all levels, with the tools for styling and scaffolding placed in the Customizer.

Read more ...

After activating BootCMS, a developer should configure some basic settings in WordPress Settings, including what the website will display as its first page.

Whatever the homepage is - a list of posts or a static page - it is advisable to enter some Lorem ipsum temporarily and create a couple of additional pages if needed. This provides some initial content while creating the Primary Menu, Header, Footer and applying styles to the foundational elements.

After creating a couple of posts and/or pages, the remaining configuration can be carried out from the Customizer (Appearance > Customise), which also provides a live Preview of the changes.

Understanding BootCMS

1. Theme as a foundation
BootCMS provides the basic scaffolding for a webpage: a Header at the top, a Navigation bar, the Main section where the page content is displayed, a Footer at the bottom and a Sidebar at the right of the page. On the first page, it also provides a place above the Main section for the Hero unit. In addition, BootCMS provides several more sidebars, giving users greater flexibility when configuring the scaffolding.
 
Read more ...
2. Classic theme with Block Editor support
BootCMS is a classic theme, which means it uses the familiar WordPress interface that has been used for many years. However, the modern Block Editor is also available for editing pages.
3. Customizer as the control centre
Configuration of the scaffolding, styles and widgets takes place in the Customizer, with changes previewed live. For beginners, several controls are available, including tick boxes, radio options and other simple settings. More advanced users can customise the site further by editing widgets and placing them in the appropriate areas, allowing more complex setups.
4. Frameworks & Libraries
BootCMS provides the option to select from several CSS and JavaScript frameworks or libraries simply by using a control in customizer. The necessary framework files are automatically linked from their respective CDNs.
5. Content and presentation are separate
Following the standards and guidelines of the W3C, BootCMS keeps content and presentation separate. The structure, behaviour and styling are implemented through the BootCMS tools and the Customizer, while content is added through the familiar WordPress Pages and Posts.

Schema Microdata

BootCMS theme includes in its HTML, Microdata vocabulary conforming to the Schema.org organisation. Schema.org is supported by most major search engines on the Internet, including Google, Bing, Yahoo and Yandex. Microdata is used by online bots to understand the webpage content more easily and help developers get the maximum benefit from their efforts.

Read more ...

BootCMS uses the Schema.org Microdata to "mark" several parts of a webpage, such as the Header, the Footer, etc., and to add a small amount of information about the creation of the webpage, such as the Author and the Date Published. In this way, it does not interfere with other Schemas which the developer may need to add. In fact, BootCMS's Microdata helps any added schema.

There are two parts of Microdata used by BootCMS in the theme:

WebPage Structure (Hardcoded)
  • <body itemscope itemtype="https://schema.org/WebPage">
  • <header itemprop="hasPart" itemscope itemtype="https://schema.org/WPHeader">
  • <nav aria-label="main navigation" itemprop="hasPart" itemscope itemtype="https://www.schema.org/SiteNavigationElement">
  • <main itemprop="mainContentOfPage" itemscope itemtype="https://schema.org/WebPageElement">
  • <footer itemprop="hasPart" itemscope itemtype="https://schema.org/WPFooter">
Page Information (Optional)
In the Pages editing section of WordPress, under each page, BootCMS adds entries in the Custom Fields which can be used to provide information regarding the creation of the webpage. This is optional, and if the "Value" field has not been filled in, the entry is not added to the HTML.
  • <meta itemprop="name" content=" ">
    The title of the webpage. If no one is provided, the theme uses the Title of the webpage.
  • <meta itemprop="description" content=" ">
    A short description of the webpage, recommended to be up to around 160 characters.
  • <meta itemprop="keywords" content=" ">
    It is recommended to use the Focus Keyword (the main keyword) of the page, together with two or three Related Keywords.
  • <meta itemprop="inLanguage" content=" ">
    The language of the page such as "en-GB".
  • <meta itemprop="author" content=" ">
    The name of the author of the webpage.
  • <meta itemprop="datePublished" content=" ">
    Date published is added automatically by WordPress.
  • <meta itemprop="dateModified" content=" ">
    Date modified is added automatically by WordPress.
  • <link itemprop="isPartOf" href=" ">
    This is added automatically by WordPress, it is a link pointing to the WebSite.

Scaffolding

A complete scaffolding includes several sidebars to provide maximum flexibility for developers. The developer has full control over the webpage layout. Widgets can also be used to edit the main sections of a page as a whole, such as the Header, Nav bar, Right Sidebar and Footer. All editing takes place in the Customizer, including HTML, CSS and JS. Remember to use the BootCMS Large HTML Editor widget for a more comfortable editing experience.

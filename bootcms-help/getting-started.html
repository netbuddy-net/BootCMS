Getting Started

Overview

Thank you for choosing BootCMS as your WordPress theme. This is Version 2.0, published in October 2026.

BootCMS takes a different approach to helping HTML, CSS and JS developers create websites. Rather than imposing a specific page layout, BootCMS provides a basic, flexible structure that allows developers of all levels, from beginners to advanced, to start building immediately and see the results with only a few clicks.

Read more ...

The theme and the resources it uses are designed to remain lightweight, providing the essential foundations without adding unnecessary features or styling.

BootCMS is a classic WordPress theme, so most of the tools and methods will be familiar to developers who work with the classic WordPress approach. At the same time, it remains fully compatible with the WordPress Block Editor, allowing content to be created using blocks when required.

The Customizer is used extensively to provide simple ways to configure the site's structure, apply classes and control basic theme functionality without requiring changes to the theme files. For more advanced developers, BootCMS also provides additional areas, including widgets, where custom HTML, CSS and JavaScript can be used, allowing the theme to remain flexible as development requirements grow.

Installation and Activation

To install the BootCMS theme, after installing and setting up WordPress, visit Appearance > Themes, and click Add Theme at the top to open the WordPress theme library.

At the top right, enter "BootCMS" in the Search Themes field. WordPress will display the BootCMS theme. Hover over the theme image and click Install.

Alternatively, while in the theme library, and if the BootCMS theme package is already available as a "Zip" file, click Upload Theme at the top. Click the displayed Choose file button to select the "Zip" file and then click Install now to install the theme.

After BootCMS has been installed, return to Appearance > Themes and hover over the BootCMS image. Click Activate to activate the theme.

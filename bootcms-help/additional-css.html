Additional CSS

WordPress provides a "textarea" box, where developers can add their own CSS code to customise the appearance and layout of the site.

BootCMS provides two additional classes to assist with typography.
 
Columns
The columns2 class, with versions supporting up to five columns: columns3, columns4 and columns5. These classes can be applied to any element containing "p" tags (paragraph) at any descendant level, or directly to a "p" tag itself.
Using CSS classes instead of HTML to split paragraphs into columns preserves semantic structure and benefits SEO and accessibility.
 
Drop Cap
The dropcap class, which can also be applied to any element containing "p" tags at any descendant level, or directly to a "p" tag itself. A drop cap emphasises the first letter of a paragraph.

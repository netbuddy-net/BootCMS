Advanced Settings

JS Libraries & Frameworks

The BootCMS theme provides an easy way for developers to enable JavaScript libraries and/or frameworks. Enable any of them by selecting the relevant checkbox. The required JavaScript library or framework, together with its corresponding application JS file, is automatically linked to the front end. No PHP code is required to link these files.

  1. Enable WordPress jQuery - jQuery code can be edited in the existing main JS file "./js/script.js".
  2. Enable WordPress React (wp.element) - A JS file "./js/react-app.js" is already provided to start editing immediately.
  3. Enable Vue on CDN - A JS file "./js/vue-app.js" is already provided to start editing immediately.

CSS Libraries & Frameworks

Select the related radio button for the CSS library or framework of choice.

  1. BootCMS (native) - This is the framework enabled by default when the BootCMS theme is activated.
  2. Bootstrap - Links the Bootstrap framework's CSS and JS files from a CDN.*
    Bootstrap Version
    When Bootstrap is selected, the Bootstrap Version dropdown menu appears, allowing a choice between versions 4 and 5.
  3. Bootswatch - Links the Bootswatch CSS and Bootstrap JS files from a CDN. Bootswatch is version 5.*
    Bootswatch theme
    When Bootswatch is selected, an input box appears to enter the name of the Bootswatch theme of choice. The available theme names are displayed above the input box.
  4. Foundation - Links the Foundation framework's CSS and JS files from a CDN.*
    Foundation Version
    When Foundation is selected, the Foundation Version dropdown menu appears, allowing a choice from several versions of Foundation.
  5. Bulma 1.0.4 - Links the Bulma CSS file from a CDN. Bulma is a CSS library and does not require JS.

* : When using Bootstrap or Bootswatch, the required classes for the Navbar must be entered in the "Simple Styles / Global Section / Nav Tag Classes - Global" control, in order to use the WordPress Menu in Primary Navigation.
With the Foundation framework, the WordPress Menu in Primary Navigation works only with version 6.x.

Disable WP Modules

Disable Block Editor
BootCMS is s classic theme but supports the Block Editor for pages and posts. If the Block Editor is not needed, disable it here by selecting the checkbox.
Disable WordPress Emojis
WP Emojis may no longer be needed since modern Operating Systems support Emojis. To disable the WP Emoji code loaded on the frond end, select this checkbox.

Amend the 404 (Not Found) file

404 Page (Not Found) Title
Enter a title in the input box to replace the default title.
Custom HTML 404 content
Enter any text in the "textarea" box to replace the default content. Up to 500 characters are supported.
404 Page Image
Select an image with the image control to replace the default image.

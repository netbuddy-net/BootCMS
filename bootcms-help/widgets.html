Sidebars

A Sidebar is a location within a webpage registered by BootCMS for placing widgets. All sidebars registered by BootCMS are listed in the "Widgets" section.

When a particular page is being previewed, any sidebar that is not part of that page will not be displayed in the list of available sidebars.

Add a Widget

Click on any sidebar link to display the widgets currently assigned to it. To add a widget, click the "Add a Widget" button. A list of available widgets will be displayed, click on any widget to add it to the sidebar.

Notice the BootCMS Large HTML Editor widget. This is a free tool, provided by BootCMS allowing developers to write HTML/CSS/JS code comfortably within the Customizer interface.
